# Hermes + 9mem

Use this repository's Markdown wiki as the durable, shared knowledge base. Hermes's built-in `MEMORY.md` and `USER.md` are separate, small, always-loaded snapshots; do not copy the whole wiki into them.

## Start of a task

1. Resolve the central vault from `.9mem/config.json`; by default it is this repository root.
2. Read `SESSION.md` for active work and `index.md` for the wiki map.
3. Before research or task execution, create `wiki/tasks/YYYY-MM-DD/<task-slug>.md` with `node tools/9mem.mjs start-task "Task description" --project owner/repo`. Fill in the user's request and an actionable plan before doing the work. Use `global` if no project applies.
4. Search the wiki for relevant context before asking the user to repeat information or creating a new page. Use `node tools/9mem.mjs search <terms>` with Node.js 22 or newer.
5. Read only relevant pages and follow links as needed. Treat notes as fallible; check sources for time-sensitive or consequential claims.
6. Keep project instructions and workflows in this file (or a narrower nested `AGENTS.md`), not in personal Hermes memory.

## Saving knowledge

- Put durable, reusable facts in the appropriate `wiki/` page and add links from the relevant index/page. Append completed work to `log.md`; update `SESSION.md` for current status.
- Capture each task's milestones in its task record using `node tools/9mem.mjs milestone <task-file> "Milestone description"`; at completion record files, decisions, verification, and remaining work, then run `node tools/9mem.mjs complete-task <task-file> "Completion summary"`.
- Put concise user preferences/profile facts in Hermes `USER.md` only when appropriate. Put only high-value, cross-session agent/environment notes in Hermes `MEMORY.md`; use that small memory to point back to this repository rather than duplicate wiki content.
- Do not save secrets, credentials, speculative claims, or transient task details as durable memory. Attribute claims to sources and distinguish generated/authored content from independently verified facts.
- Avoid duplicate pages: search first, then update the canonical page. Preserve history in the append-only log.

## Validation

Run `node tools/9mem.mjs check-frontmatter` and `node tools/9mem.mjs check-links` after wiki edits with Node.js 22 or newer. Never claim a check passed unless its command exits successfully.

Use one central 9mem vault for all task records and durable memory. The repository root is the default; change it only to an existing initialized 9mem vault with `node tools/9mem.mjs set-vault <path>`. This only changes local configuration; it does not migrate files.

Hermes loads project context at session start. If this file changes during a session, start a new session before expecting Hermes to use the updated instructions.
